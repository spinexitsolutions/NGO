# Admin guide (for non-technical staff)

Sign in at **/admin**. What you can see depends on your role.

## Change how the website looks — *Website → Theme & branding*
1. Pick a **preset** or adjust **colours**, **typography**, **buttons & cards**, **layout** and **motion**.
2. Watch the **live preview** on the right (switch between desktop, tablet and phone, and between pages).
   The accessibility box warns if text would be hard to read.
3. Changes save automatically as a **draft** — visitors don’t see them yet.
4. Click **Publish**. Visitors see the new design within about a minute.
5. Made a mistake? **History → Restore** brings back any previously published version (into the draft),
   **Discard** throws away unpublished edits, **Reset** returns a group to defaults.

Logo, favicon, organisation name, contact details, announcement bar, footer text, donation settings,
SEO and analytics are in **Site settings**; menus are in **Navigation**. Both work the same way (draft → publish).

## Edit pages — *Website → Pages & sections*
- Open a page. On the left is its list of **sections**: drag ⠿ to reorder, 👁 to hide/show, copy to duplicate, bin to remove.
- Click a section to edit its text, images and buttons on the right. **Reset** restores the section’s defaults;
  **Save as template** lets you reuse a configured section on other pages.
- **Add section** offers 30 section types (hero, image + text, statistics, causes, campaigns, donation banner,
  FAQs, team, documents, forms, video, timeline…). Sections marked “shows live data” display content you
  manage elsewhere (e.g. Causes) — you only set the heading and options there.
- **Preview draft** shows the page exactly as visitors will see it. **Publish** checks every section first and
  tells you what to fix. **Schedule** publishes automatically at a chosen time. **Versions** restores older versions.
- **New page** creates custom pages (e.g. “/annual-gala”) that can be linked from the menu.

## Content — causes, campaigns, projects, events, stories, team, blog…
Each type has a list with search, status filter, duplicate and CSV export, and an editor. Set **Status** to
publish/archive. Stories and testimonials **cannot be published without recorded consent**. Project budgets and
beneficiary counts show publicly only when you tick the “approved/verified” boxes. Items marked **Sample** came
with the demo — edit or delete them before launch.

## Media library
Upload images, videos and PDFs (drag & drop). Images are optimised automatically. Always add **alt text**
(a short description for people using screen readers). **Replace file** swaps an image everywhere it is used.
The library shows where each file is used and warns before deleting something in use.

## Donations
- Totals everywhere include **only verified successful payments** — pending and failed payments are shown separately.
- **Record offline donation** for bank transfers, cheques or cash (with the bank/cheque reference). It is audit-logged.
- On a donation you can download/email the **receipt**, **refund** (partial or full), or **void** a receipt
  with a reason (optionally issuing a corrected one). Everything is recorded in the audit log.

## Volunteers, events, inquiries
Review applications (approve, reject, request information — the applicant is emailed), assign approved
volunteers to projects/events, and record hours. Event pages show registrations, waitlist and attendance;
cancelling an event emails everyone registered. Inquiries from all forms arrive in **Inquiries**.

## Good practice
- Never publish children’s names, faces without guardian consent, addresses, medical or identity details.
- Only claim tax benefits, registrations, partners and statistics you can prove.
- Turn on **two-factor authentication** in *My account*.
